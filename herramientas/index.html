Documentar una visita técnica

AuditaPC

Inventario técnico local de equipos, con historial e informes exportables.

Windows 10 / 11 x64 · Estable · 1.0.0

Ver ficha de AuditaPC

Windows 10 / 11 x64 · Estable · 1.0.0

Aplicación portable para realizar inventarios técnicos y documentar visitas presenciales a equipos Windows.

Qué resuelve

Permite reunir información técnica de distintos computadores dentro de una auditoría organizada por empresa y fecha, manteniendo historial y generando informes.

Qué incluye

  • Identificación de hardware y características del equipo.
  • Información de Windows, software y componentes.
  • Registro de observaciones e intervenciones.
  • Historial de capturas.
  • Notas de terreno y fotografías.
  • Informes HTML individuales y consolidados.
  • Exportación CSV y JSON.

Tecnologías

.NET 10WPFWMI

Licencia

Código fuente y ejecutable
MIT
Documentación
CC BY 4.0

Funciona localmente, es portable y no necesita conexión a Internet para el levantamiento habitual. Los datos quedan en el equipo: no se envían inventarios a servidores de terceros.

Límite. AuditaPC consulta y documenta. No administra equipos, no realiza mantenimiento remoto ni modifica la configuración del sistema.

Nokto

Consola de escritorio para telemetría, audio y rutinas de automatización.

Windows 10 / 11 x64 · Versión 2.0.3

Ver ficha de Nokto

Windows 10 / 11 x64 · Versión 2.0.3

Consola de escritorio para telemetría, audio, operaciones y automatización de rutinas en Windows.

Qué resuelve

Reúne información del equipo, controles cotidianos y acciones automatizadas en una consola local configurable.

Qué incluye

  • Telemetría de CPU, memoria, GPU y red.
  • Control de dispositivos de audio y micrófono.
  • Reproductor musical y funciones asociadas.
  • Avisos y notificaciones del sistema.
  • Temporizadores, alarmas y Pomodoro.
  • Editor de rutinas mediante bloques y disparadores.
  • Ejecución concurrente de tareas.
  • Control desde dispositivos móviles dentro de la red local.
  • Galería de evidencias de pantalla.

Tecnologías

Preparar datos para una prueba

DatosDemoCL

Generador local de datos de prueba con convenciones chilenas.

Windows · Python 3.11+ · Versión 0.8.0

Ver ficha de DatosDemoCL

Windows · Python 3.11+ · Versión 0.8.0

Generador local de datos sintéticos con convenciones chilenas para probar aplicaciones, formularios, importadores y sistemas de información.

Qué resuelve

Evita tener que inventar registros manualmente o utilizar información real de clientes para realizar pruebas.

Qué incluye

  • Generación de RUT con dígito verificador coherente.
  • Nombres y apellidos ficticios.
  • Regiones y comunas chilenas.
  • Fechas y montos en pesos chilenos.
  • Datos de clientes, ventas y comercio de demostración.
  • Selección de campos y perfiles.
  • Vista previa de registros.
  • Generación mediante interfaz gráfica.
  • Interfaz CLI.
  • Exportación CSV y JSON.
  • Semillas reproducibles para repetir los mismos lotes.

Tecnologías

Python 3.11+TkinterBiblioteca estándarCSV / JSON
