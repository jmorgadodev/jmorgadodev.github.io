El desafío

Datos públicos, fuentes distintas, una lectura más clara.

La información pública está distribuida en distintos orígenes, formatos y fechas de actualización; consultarla y compararla exige trabajo de depuración.

Cómo funciona

De la fuente oficial a la consulta.

El diagrama muestra el recorrido completo: las fuentes oficiales, la validación que conserva la evidencia de cada registro, el lago de datos y, al final, la API y el sitio. Selecciona cada bloque para ver su función; el tema acompaña al del sitio.

La solución

Un proceso con la evidencia a la vista.

El sistema separa lo que ocurre antes y después de publicar: la ingesta reúne y normaliza, la validación exige que cada registro conserve su origen, el lago conserva el histórico y las capas finales responden consultas.

La misma fuente, verificada en cada etapa.

01

Recopilar

Once fuentes oficiales del Estado se descargan por rangos y se normalizan con un conector por fuente.

02

Verificar

Cada registro conserva su URL oficial y un checksum; el proceso se detiene si un lote pierde evidencia o cae de tamaño.

03

Consultar

El lago alimenta una API pública y un sitio con fichas, cruces y rankings, siempre con su origen a la vista.

El siguiente paso

Primero entender de dónde viene la información.

El Cambiómetro nació de una pregunta simple: si la información pública ya existe, ¿por qué cuesta tanto compararla? La respuesta fue ordenar el proceso antes de publicar los datos. Ese mismo enfoque guía mi trabajo: entender el problema, construir la base y recién después abrir la puerta.
