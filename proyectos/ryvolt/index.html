Una presencia corporativa bilingüe con dos enfoques visuales, interacción y una base técnica preparada para buscadores.

01 / Qué se resolvió

Dos registros visuales para explicar una misma marca.

Explicar servicios de consultoría y conectar con públicos diferentes sin perder una identidad reconocible.

Trabajo desarrollado

Implementación frontend responsive y bilingüe, experiencias Corporate/Rebel, componentes interactivos, formularios, analítica y técnicas de prerenderizado y SEO.

Por qué lo construí así

Usé componentes de React para sostener las dos propuestas visuales y la navegación bilingüe. El prerenderizado entrega contenido inicial a buscadores y conserva las interacciones en el navegador.

Mi participación

Implementé el frontend bilingüe, las interacciones y el prerenderizado.

Resultado

Una web adaptable con dos registros visuales para presentar los servicios de la marca.
